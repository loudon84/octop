# Tasks

本变更是第一阶段的用户范围增量，功能/测试交由 GPT-6 Luna subagent，控制器负责接口冻结、执行细节和独立审查协调。每项先提供精确路径/输入输出/验收 brief 与基线，再编码；不提交或推送。既有 P07c2d 修复、P08 通用容器及使用已冻结动作的共享连接/员工显式授权/专家共享绑定设置可独立继续；私库开通状态、联合来源选库及相关检索/证据页面需等待本变更对应来源合同完成。先交付的共享设置不得猜测新增私库动作、伪装私库已可用或扩大授权，私库页面仍按本变更验收。
